## Constats utiles pour les runs suivants
- Dépôt public : les runners macOS de GitHub Actions sont gratuits.
- Le clone des sessions est superficiel (50 commits) : `git rev-list --count HEAD` y donne un faux numéro. Faire
  `git fetch --unshallow origin main` avant de calculer un numéro de version ; dans les workflows,
  `fetch-depth: 0` (comme `play-bundle.yml`).
- 17 plugins natifs maison côté Android (`registerPlugin` dans `app/src/services/`) ; sur iOS,
  `isNativePlatform()` est vrai, donc chaque service doit avoir un repli propre tant que l'équivalent Swift n'existe
  pas.
- `@capgo/capacitor-health` annonce HealthKit + Health Connect ; le patch du dépôt ne touche que l'Android.
- `@capacitor/cli` 7.6 contre `@capacitor/core` 8.2 : ne pas monter la CLI dans `package.json` (Android s'en sert) ;
  côté iOS, utiliser la CLI 8 seulement dans les workflows iOS si besoin.
