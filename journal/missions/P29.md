# Mission P29 — Retirer le rôle Éditeur du compte de service Compute par défaut

- **Voie** : b. La CI n'a pas (et ne doit pas avoir) de droit d'administration IAM.
- **Durée** : 3 min. **Quand** : maintenant, pas urgent.
- **Pourquoi** : `81378799481-compute@developer.gserviceaccount.com` a `roles/editor` (réglage par défaut de Google).
  Ni le relais (`relay-runtime`) ni la CI (`gh-deployer`) ne l'utilisent ; ce rôle large ne sert à rien.

## Étapes

1. Ouvrir https://console.cloud.google.com/iam-admin/iam?project=healthtrack-824b26
2. Vérifier le projet **healthtrack-824b26**.
3. Dans le filtre, taper `81378799481-compute`. Une ligne « Compute Engine default service account » doit apparaître
   avec le rôle **Éditeur**. Si elle n'a pas ce rôle : s'arrêter, rien à faire.
4. Avant tout changement, vérifier qu'aucun service Cloud Run n'utilise ce compte : ouvrir
   https://console.cloud.google.com/run?project=healthtrack-824b26 , ouvrir chaque service → onglet
   **Sécurité** (ou « Révisions » → révision active) : le compte affiché doit être
   `relay-runtime@healthtrack-824b26.iam.gserviceaccount.com`. Si un service affiche le compte Compute : s'arrêter et
   le dire à la routine.
5. Revenir à la page IAM, ligne du compte Compute → icône crayon **Modifier le compte principal** → sur le rôle
   **Éditeur**, icône corbeille → **Enregistrer**. Ne toucher à aucune autre ligne ni aucun autre rôle.

## Vérification finale

Le filtre `81378799481-compute` ne montre plus le rôle Éditeur (la ligne peut disparaître) ; les lignes
`gh-deployer` et `relay-runtime` gardent leurs rôles.

**Capture attendue** : la page IAM filtrée. **Phrase de retour** : « P29 fait ».
