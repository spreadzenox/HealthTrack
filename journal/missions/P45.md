# Mission P45 — Adresse de commentaires du test fermé, puis relevé anonyme des commentaires

- **Voie** : b (aucune API ne lit les commentaires d'un test fermé). **Durée** : 3 min, puis 5 min aux jours 4, 8 et
  11 du test (J = 08/11 : les 12/11, 16/11 et 19/11).

## Partie 1 — l'adresse (une fois)

1. Ouvrir https://play.google.com/console → **Halcya** → **Tester et publier** → **Tests** → **Test fermé** →
   piste **Alpha** → onglet **Testeurs**.
2. Champ « Adresse e-mail ou URL pour les commentaires » : s'il est rempli, ne rien changer. S'il est vide :
   ouvrir dans un autre onglet **Halcya → Développer sa présence sur le Store → Paramètres du Store → Coordonnées**,
   copier l'adresse e-mail **publique** déjà affichée, la coller dans le champ, **Enregistrer**.
3. Noter sans le copier dans le dépôt le nombre de testeurs inscrits s'il est affiché.

## Partie 2 — relevé des commentaires (jours 4, 8, 11)

1. **Halcya** → **Notes et avis** → **Commentaires des testeurs** (ou « Testing feedback »).
2. Pour chaque commentaire des 4 derniers jours, écrire **une phrase anonyme** : thème (repas, digestion,
   bien-être, Sources, abonnement, plantage…), ce qui gêne, version si affichée. Jamais de nom, d'adresse,
   de photo ni de donnée de santé personnelle.
3. Ouvrir aussi la boîte de l'adresse publique si le propriétaire le demande, avec la même règle.

## Vérification finale

Partie 1 : le champ affiche l'adresse. Partie 2 : une liste de phrases anonymes, une par commentaire.

**Capture attendue** : l'onglet Testeurs (partie 1). **Phrase de retour** : « P45 fait », puis aux jours 4, 8, 11 :
« Retours testeurs : » suivi des phrases anonymes (la routine les range dans `RETOURS-TESTEURS.md`).
