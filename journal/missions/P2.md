# Mission P2 — Modifier l'activité de l'auto-entreprise

- **Voie** : b pour préparer, **c** pour signer et valider (déclaration administrative, vérification d'identité).
- **Durée** : 15 min. **Quand** : seulement quand vous aurez décidé de le faire (à vous de décider, étapes écrites le
  02/11). Rien ne bloque le test fermé.
- **Constat (02/11)** : activité déclarée NAF 62.01Z (programmation informatique) ; la vente d'un logiciel standard
  par abonnement relève plutôt de 58.29 (édition de logiciels). À vérifier avant : si la nature devient commerciale,
  la catégorie fiscale (BNC → BIC) et le taux de cotisations peuvent changer (simulateur de l'URSSAF ou comptable).

## Étapes

1. Ouvrir https://formalites.entreprises.gouv.fr . Si la page demande de se connecter : **vous** vous connectez
   (Claude ne saisit aucun identifiant), puis rendez la main.
2. **Modifier une entreprise** → saisir le SIREN (affiché sur votre espace ; Claude le lit à l'écran, ne l'écrit nulle
   part ailleurs).
3. Choisir **Activité** → « Modification de l'activité principale » (ou « Ajout d'une activité » si vous gardez la
   programmation pour des clients : dites lequel en lançant la mission).
4. Description de l'activité, telle quelle : « Édition et vente par abonnement d'une application mobile, distribuée
   par les boutiques d'applications ».
5. Date d'effet : la date que vous donnez en lançant la mission (aujourd'hui ou le 1er du mois).
6. Aller jusqu'à la page de récapitulatif et **s'arrêter** : la signature électronique et la validation sont les
   vôtres.

## Vérification finale

Récapitulatif avec la nouvelle description et la date d'effet, pas encore signé.

**Capture attendue** : le récapitulatif. **Phrase de retour** : « P2 envoyée » (après votre signature).
