# Mission P50 — Débloquer GitHub Actions (problème de facturation du compte GitHub)

- **Voie** : b jusqu'à l'écran de paiement, **c** pour le paiement lui-même (geste du propriétaire).
- **Durée** : 5 min. **Quand** : **maintenant**. Tant que ce n'est pas fait, plus aucun test, aucune release, aucun
  envoi Alpha ni TestFlight, aucun merge de la routine.

## Constat (17/11, run de 19:30)

Depuis le 17/11 vers 18:40 (heure de Paris), chaque job GitHub Actions du dépôt échoue sans démarrer, avec ce message
de GitHub : « The job was not started because your account is locked due to a billing issue. » Dernier workflow passé
sur main : Tests et émulateur A56 de 0bc5c27 (17/11, 18:09). Premier refusé : les checks de la PR #1090 (18:41).
Le dépôt est public : les minutes Actions ordinaires y sont gratuites ; le blocage vient du compte, pas du dépôt
(moyen de paiement refusé ou facture en retard, d'un autre produit GitHub par exemple).

## Étapes

1. Ouvrir https://github.com/settings/billing (compte **spreadzenox**, connecté).
2. Lire le bandeau en haut de la page (« payment failed », « past due », « account locked »…) et noter son texte exact.
3. Ouvrir **Payment information** (https://github.com/settings/billing/payment_information) : noter si le moyen de
   paiement est expiré ou refusé.
4. S'arrêter là : **mettre à jour la carte ou régler la facture est le geste du propriétaire.** Ne rien supprimer, ne
   rien résilier, ne changer aucun plan ni aucune limite de dépense.
5. Après le règlement (par le propriétaire), ouvrir
   https://github.com/spreadzenox/HealthTrack/actions et vérifier qu'aucun nouveau job n'échoue avec « account is locked ».

## Vérification finale

Le bandeau de facturation a disparu ; un workflow relancé (par exemple « Tests » de la PR #1090, bouton
« Re-run all jobs ») démarre vraiment (des étapes s'affichent dans le job).

**Capture attendue** : aucune (pas de donnée de paiement dans le dépôt). **Phrase de retour** : « P50 fait », ou le texte
exact du bandeau si le blocage reste.
