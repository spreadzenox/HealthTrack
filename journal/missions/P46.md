# Mission P46 — Faire expirer les avis au bout de 90 jours (Firestore `feedback`)

- **Voie** : b. Geste unique ; la voie a demanderait `roles/datastore.indexAdmin` pour `gh-deployer`, inutile ici.
- **Durée** : 3 min. **Quand** : maintenant (le formulaire « Votre avis » est dans l'app).
- **Pourquoi** : le relais range chaque avis avec une date `expireAt` ; sans règle d'expiration, Firestore les garde
  sans limite. Même geste que P33 (déjà fait pour `credits`).

## Étapes

1. Ouvrir https://console.cloud.google.com/firestore/databases/-default-/ttl?project=healthtrack-824b26
   (Firestore → base « (default) » → **Durée de vie (TTL)**).
2. Vérifier le projet **healthtrack-824b26**. La liste doit déjà montrer une règle `credits` / `expireAt`.
3. Si une ligne `feedback` / `expireAt` existe déjà : ne rien faire, aller à la vérification.
4. Sinon : **Créer une règle** → Groupe de collections : `feedback` → Champ d'horodatage : `expireAt` → **Créer**.
5. Attendre que l'état passe de « Création » à « Actif » (quelques minutes ; recharger la page).

## Vérification finale

Ligne `feedback` · `expireAt` · état **Actif**, et la règle `credits` toujours présente.

**Capture attendue** : la liste des règles TTL. **Phrase de retour** : « P46 fait ».
