# Mission P32 — Pays de la production

- **Voie** : b pour les pays, **c** pour « Promouvoir la version » (la mise en production reste votre clic).
- **Durée** : 5 min. **Quand** : le jour où P30 est accordée, avant la mise en production.
- **Décidé le 02/11** : France, Belgique, Suisse, Luxembourg, Canada, sans les États-Unis.

## Étapes

1. Ouvrir https://play.google.com/console → **Halcya** → **Tester et publier** → **Production** → onglet
   **Pays/régions**.
2. **Ajouter des pays/régions** → cocher **Belgique, Canada, France, Luxembourg, Suisse**, rien d'autre (surtout pas
   États-Unis) → **Ajouter** → confirmer. Si l'un est déjà présent, ne pas le décocher.
3. Ouvrir **Tests → Test fermé → Alpha** : relever le code de la version en tête (celle que la routine indique en
   tête du résumé ; s'arrêter si elles diffèrent).
4. Sur cette version : **Promouvoir la version → Production**, remplir les notes de version avec le texte donné par la
   routine en tête du résumé, aller jusqu'à la page de vérification. **S'arrêter** avant « Enregistrer et publier » /
   « Envoyer pour examen » : ce clic est le vôtre.

## Vérification finale

Production → Pays/régions : exactement Belgique, Canada, France, Luxembourg, Suisse. Version préparée, pas publiée.

**Capture attendue** : la liste des pays et la page de vérification. **Phrase de retour** : « P32 fait,
production lancée » (après votre clic).
